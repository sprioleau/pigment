# Pigment soundtrack

**Children's March Theme** by Cleyton Kauffman.

- Source: https://opengameart.org/content/childrens-march-theme
- Composer: https://soundcloud.com/cleytonkauffman
- License: Creative Commons Zero (CC0 1.0 Universal)
- License terms: https://creativecommons.org/publicdomain/zero/1.0/
- Original download: https://opengameart.org/sites/default/files/childrens_march_theme.zip

The source page and included readme identify this asset as CC0. The composer describes it as a seamless 64-second loop. Pigment's copy is converted from the original WAV to mono 22,050 Hz, 16-bit PCM WAV for a smaller download and broad browser compatibility. A 5-millisecond cosine fade at each endpoint prevents a sample discontinuity from producing a click at the loop seam. The arrangement and 64-second loop duration are preserved.
